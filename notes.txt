DEACTIVATING A MEMBER
According to the RSI API, all members will continue to stay active each month unless we notify RSI that the member has not been paying their monthly subscription.  
Stage 1:
In the Flight backoffice, when a member clicks on the link to access their travel portal access (Passport Lite, Passport (Dashlife), Passport Travel Agent), the Flight system needs to check if they have purchased that corresponding SKU (with the corresponding product classification) within the past 45 days.  
Product Classifications:
Passport Lite: Passport Lite
Passport (DashLife/Travology): Passport (DashLife)
Passport Travel Agent: Travel Agent

Stage 2 (Separate billable project):
Flight will develop a daily check to see if the person has purchased in the current day plus the previous 44 days.  If not, then Flight will deactivate the account through the RSI API.  

To deactivate a member:
POST TO: https://middleware.accessrsi.com/api/members/createupdate/<Org Id the member is in>/jwt
JWT Encrypt Body
{
   "id": "<Your Identifier for this customer>",
   "isActive": false;
   "blockReason": "<Reason the member is blocked.  Only add if isActive is set to false>"
} 

Notice to Member/Affiliate (Customer/Consultant) if they try to click on a Travel Portal link in the backoffice and have not purchased in the past 45 days.

    // If root homepage
    if ( $request_uri === '' ) {
        wp_redirect('https://dashlifetravel.com/', 301);
        exit;
    }

    // If vanity affiliate like /jake, /maria, etc
    if ( preg_match('/^[a-zA-Z0-9_-]+$/', $request_uri) ) {
        wp_redirect('https://dashlifetravel.com/?ref=' . urlencode($request_uri), 301);
        exit;
    }

    // Otherwise, let WordPress handle it
});
